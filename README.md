# GIS and Remote Sensing in Geology

> Geospatial workflows for geological mapping, terrain analysis, and remote-sensing interpretation.

## About

This repository records reproducible GIS and remote-sensing workflows relevant to geological investigations. Example work may use QGIS, GDAL, Python geospatial libraries, satellite imagery, digital elevation models, and openly licensed spatial datasets.

Every map should include its data sources, date, projection/CRS, scale, legend, processing steps, and limitations. Confirm dataset licences and attribution requirements before redistribution.

## Scope

- Geological and thematic map preparation
- DEM-derived slope, aspect, and hillshade
- Lineament mapping and validation
- Satellite image interpretation
- Raster and vector data processing
- Cartographic layout and metadata

## Data and scientific integrity

- Identify the source, author/organization, date, licence, and version of external data.
- Record coordinate reference systems, units, scale, and methods where relevant.
- Do not invent field observations, analytical results, coordinates, or citations.
- Label synthetic/demo data clearly; never present it as field or laboratory data.
- Include uncertainty, assumptions, and limitations in interpretations.
- Respect site access, safety, privacy, and data-sharing restrictions.

## Tools

Add only tools actually used in a project. Potential tools include QGIS, Python, GDAL, spreadsheet software, and relevant geological/analytical software.
